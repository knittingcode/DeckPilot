## Code signing

| Build | Code signature | Notarized |
| ----- | -------------- | --------- |
| aarch64-apple-darwin | Developer ID | yes |
| x86_64-apple-darwin | Developer ID | yes |
| x86_64-pc-windows-msvc | **unsigned** | n/a |
| x86_64-unknown-linux-gnu | **unsigned** | n/a |

Every updater package is signed with the DeckPilot updater key and verified by the app before installing. "Unsigned" means no platform code signature: Windows SmartScreen or Gatekeeper may warn, and Linux packages are not signed by a distribution key.
